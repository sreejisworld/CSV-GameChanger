Risk Strategist
Agents/risk_strategist.py
GAMP 5 risk-based approach. Maps ServiceNow criticality → Severity, change type → Occurrence. Calculates RPN (1–27), applies patient-safety override, and returns CSA testing strategy.
RPN Patient Safety URS-3.x / 4.x

Requirement Architect
Agents/requirement_architect.py
Generates structured URS documents from natural language using Pinecone similarity search over GAMP 5/CSA text. Classifies criticality, builds regulatory rationale, and transforms URS into UR/FR documents with risk matrix.
URS Gen Pinecone OpenAI Embed URS-6.x / 16.x
🔍
Verification Agent
Agents/verification_agent.py
Reviews URS drafts against live GAMP 5 text in Pinecone. Runs three independent checks: criticality alignment, rationale relevance (min score 0.45), and contradiction scan (four domain pairs). Rejects non-compliant drafts.
Reject Approve Pinecone URS-12.x
🧪
Delta Agent
Agents/delta_agent.py
Deterministic CSA test script generator from UR/FR documents. Routes by risk level and test type: Informal (setup + positive + negative + edge), Formal OQ (positive), Formal UAT (business-process), or exploratory charter (medium/low).
Deterministic OQ / UAT URS-17.x

Integrity Manager
Agents/integrity_manager.py
Central append-only CSV audit trail with SHA-256 tamper-evident hashing. Optionally writes dot-prefixed JSON logic-archive files capturing full AI reasoning chains (inputs → steps → outputs) cross-referenced to CSV rows.
SHA-256 21 CFR Part 11 URS-13.x

Core Data Flows
📥
ServiceNow CR → Risk Assessment
1
ServiceNow POSTs Change Request to POST /webhook/sn-change
↓
2
API/main.py validates input (cr_id, criticality, change_type) and logs CHANGE_REQUEST_RECEIVED
↓
3
Risk Strategist maps fields → Severity / Occurrence, calculates RPN, applies patient-safety override
↓
4
Integrity Manager writes RISK_ASSESSMENT_COMPLETED row with SHA-256 hash
↓
5
API returns JSON: RPN, risk level, testing strategy, patient_safety_override
📝
Natural Language → Verified URS
1
User enters requirement text in Streamlit Page 2 (Validation Factory)
↓
2
Requirement Architect embeds text via OpenAI, queries Pinecone, classifies criticality, builds regulatory rationale
↓
3
Verification Agent runs three checks (criticality, relevance, contradictions) against live GAMP 5 text
↓
4
Integrity Manager logs URS_VERIFIED or COMPLIANCE_EXCEPTION
↓
5
UI displays structured URS with verdict; user can download PDF
🧪
URS → UR/FR → CSA Test Script
1
User selects role, GxP category, implementation method on Page 4
↓
2
Requirement Architect applies risk matrix → risk level + test strategy; decomposes URS into UR + FRs with acceptance criteria
↓
3
User selects test type (Informal / Formal OQ / Formal UAT) on Page 5
↓
4
Delta Agent generates deterministic step-by-step CSA test script; logs CSA_TEST_SCRIPT_GENERATED
↓
5
UI renders tabular test steps; user downloads Excel or combined Validation Report PDF
📚
GAMP 5 PDF → Pinecone Knowledge Base
1
Admin drops PDF(s) into the docs folder and runs scripts/ingest_docs.py
↓
2
Ingestion script extracts text, splits into chunks, derives reg_version from filename
↓
3
OpenAI text-embedding-3-small converts each chunk to 1536-dim vector
↓
4
Pinecone upserts vectors with metadata: source_document, page_number, reg_version, chunk_id
↓
5
Agents query the index at runtime; new regulatory versions are detected and flagged automatically
