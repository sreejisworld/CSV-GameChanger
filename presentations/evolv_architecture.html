Key Data Flow Sequences

① Requirement → Test Script (Full Pipeline)
1
User enters plain-English requirement in Streamlit Validation Factory
↓
2
SMART Engine refines to SMART format, detects FDA/EMA flags
↓
3
Requirement Architect generates URS with GAMP 5 rationale from Pinecone
↓
4
Verification Agent runs 3-point GAMP 5 check → APPROVED / REJECTED
↓
5
Architect transforms URS → UR/FR with risk matrix (GxP × Impl → Risk Level)
↓
6
Delta Agent generates CSA test script (Informal / OQ / UAT)
↓
7
PDF Generator creates 5-page Validation Report with MoS signature page
② Risk Assessment → E-Signature Sign-off
1
Risk page — user assigns Impact × Implementation per UR/FR; risk matrix auto-calculates HIGH/MEDIUM/LOW
↓
2
⚡ Generate Test Script — React calls POST /verify/generate-script with risk rows
↓
3
Delta Agent builds UR/FR + test steps; stored in Zustand testScripts + testRuns
↓
4
Verify page — tester executes steps: Pass / Fail / Blocked / N/A per step, actual result, file evidence
↓
5
Sign & Lock — POST /verify/sign-off with signer name + meaning → SHA-256 reasoning_hash returned
↓
6
Integrity Manager appends TEST_RUN_SIGNED_OFF to audit CSV + logic archive
③ Release Authorization Chain
1
Release page — 5-point go-live checklist auto-populated from Zustand lifecycle state
↓
2

↓
3

↓
4
🚀 Approve for Release — POST /release/go-live (requires ≥1 approval)
↓
5
RELEASE_APPROVED event logged; setReleased() updates Zustand; Release badge turns green

Category 4/5 software support: risk matrix per GxP impact × implementation method
V-model lifecycle: 8 phases from Plan to Retire

URS → UR → FR traceability chain: end-to-end document lineage
Regulatory context from Pinecone: GAMP 5 Guide + CSA Guidance embedded
Verification before approval: 3-point URS compliance check

🔐 Security Architecture
CORS allowlist: only :5173 and :8501 origins accepted
Audit trail write protection: PreToolUse hook blocks direct edits
SHA-256 hash per audit row: tamper detection on every record
E-signature meaning allowlist: fixed set prevents injection
Typed Pydantic models: all API inputs validated at boundary
Error code taxonomy: CSV-001 to CSV-012, no silent failures
Logic archive integrity hash: archive file self-verifying
MCP tool sandboxing: lazy imports, no env var exposure
