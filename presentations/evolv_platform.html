Security

Defense-in-depth security model

🛡️ Claude Code Hooks

PreToolUse — protect_audit_trail.py
Blocks ANY write to output/audit_trail.csv or output/logic_archives/ at the tool-call level. Exit code 2 = hard block before execution.

🔑 Scoped API Keys

KeyStore with scope-based access control. audit-only scope enforced via dependency injection on sensitive endpoints. Keys never stored in plaintext in code.

🌐 CORS Policy

Explicit allowlist: localhost:5173, localhost:8501, localhost:3000. No wildcard origins. Credentials allowed only for listed origins.

🔐 Input Validation

Pydantic v2 models on all FastAPI endpoints. Server-side signature meaning validation (allowlist). File size limits on evidence uploads (5 MB max). No bare except:pass patterns.

📝 Typed Errors

All exceptions carry CSV-NNN error codes. No silent failures. Every exception logged to audit trail before propagation. Validation/Audit/Processing error hierarchy.

🔒 Sandbox Mode

AuditGuard middleware prevents state-changing operations in audit-only mode. TenantDictionaryMiddleware enforces tenant isolation on all responses.
